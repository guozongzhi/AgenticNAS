## 新增解析（3 篇）

### NAS：1 篇 LLM-driven NAD

1. **EvoTreeNAD**（`2609.29016v1`）：从空根生成完整可训练架构，用 persistent genealogy 和 top-percentile descendant value 路由；Idea Agent 看 lineage 历史提出变体，Code Agent 实现，短训结果与失败写回谱系。主实验每任务 3 runs，CIFAR 最多 300 iterations、MedMNIST 80；受控策略比较用 3×100 iterations。`GPT-4.1 + OSS20B` 的 100-iteration 配置平均 144 code attempts、reject 37.5%、early-stop 28.0%、0.37 GPU-days、1.91M output tokens、0.84 USD API cost。最值得保留的是对 repeated direct generation、best-of-N greedy 和 family mean 的等 100-iteration 比较，而不是与外部 NAS 的不等预算表格（PDF pp.5–8、22–23、28，Tables 1–2、6、10）。

### 固定架构 HPO：0 篇

- 没有新增同时满足“架构、数据处理与 evaluator 固定，Agent 按 trial feedback 优化 training recipe，并提供可审计预算”的论文。

### mixed-search-space：1 篇

2. **Agentic Search Spaces for Tabular Machine Learning**（`2609.16309v1`）：Agent 一次性生成 preprocessing、embedding、architecture、training、inference module candidates，随后 Optuna TPE 在 modules + default hyperparameters 的联合空间运行。小/中数据集 200 trials、大数据集 100，base/agentic attempted trials 匹配；但单 trial median fit time 可为 base 的 0.9–2.4×，且字段跨结构/训练/数据/推理，不能转写为 fixed-architecture HPO。Agent 每 model family 约 36k–103k output tokens、24–100 分钟，估计约 10 USD；failed trial 与 candidate reject 分母未报告（PDF pp.4–10、37–38，Tables 3–8、17）。

### 传统硬件感知 NAS 邻接基线：1 篇

3. **ENAS**（`2609.30272v1`）：搜索 1–6 cells、stem width、block、kernel、stride、skip、activation、expansion；每个配置 30 random + 40 mutations，3-epoch proxy 后完整训练。8 MCU × 9 resolutions 中 19/72 静态不可行，53 个可行；3 runs × 2 methods × 2 datasets 共 636 个完整训练模型、deployment pipeline failure=0，总实验约 297 CPU-hours。finalists 用 STM32 toolchain 测 peak RAM/Flash，但 MACC 仍只是 latency/energy proxy；论文没有 time-matched extended-search baseline（PDF pp.3–12，Algorithm 1、Tables 2–7）。
