## 新增解析与准确分类

### LLM-NAS：1 篇

1. **ASI-Arch / Neural Architecture Discovery via Autonomous Evolution**（`2507.18074v2`，COLM 2026 camera-ready）：开放式修改 linear-attention layer，Researcher/Engineer/Analyzer/Experience Repository 构成 proposal-feedback-memory loop。主搜索 1,773 experiments、约 10,000 exploration GPU-hours、约 20,000 total GPU-hours；105 个 340M 设计达到论文定义的 SOTA。matched 120 attempts 中 valid-result rate 37.4% vs OpenEvolve 8.3%，但主搜索缺 attempted→reject/retry/trained 完整 ledger 和 LLM tokens/费用。真实 1.3B peak memory 为 16.28–22.75 GB，却无 latency/energy/Pareto；开放代码生成也不是 typed Conv1d NAS。

### Mixed / data-selection search：2 篇

2. **Active-DiNTS**（`2610.04787v1`）：12-layer/4-resolution topology 与 cell operators 的传统 differentiable NAS，同时用 uncertainty 决定哪些 MRI volumes 被标注，归 NAS×data-selection mixed 邻接。作者报告单 V100 peak memory 14.7–17.3 GB、最快 0.21 GPU-days，但模型约 8,220–9,650 GFLOPs，baseline 数字未同代码重跑；仓库当前仅 README/LICENSE，复现缺口明显。
3. **Evolutionary Architecture Search for Chlorophyll-a Prediction**（`2610.10496v1`，AutoML4EO 2026 workshop）：同时搜索 1–6 blocks/width/block type 与 optimizer/LR/batch/epochs/EMA 等 recipe，明确归 mixed-search-space。2,720 candidates、1,827 distinct configurations、20 CPU cores 约 5 hours；最终 409-parameter MLP 是静态 1.6 kB/约 400 MAC 估计，没有真机 latency/energy。

### 传统 NAS baseline：1 篇

4. **Forecast Accuracy Is Not Trading Profit**（`2610.07825v1`）：EXAMM 传统 recurrent topology evolution，每 run 10,000 genomes，32-core CPU search 16.2±2.8 minutes/8.65 core-hours。66-weight networks 在 Raspberry Pi Zero 实测 10.82 microseconds、INA219 power above idle 476.7 mW；但无 per-inference energy、peak memory、Pareto/matched random baseline 或代码链接。

### Agentic BO / HPO 邻接：1 篇

5. **AgenticBBO-Bench**（`2610.12183v1`）：77 tasks、统一 objective-evaluation budget，invalid candidate 可同 round 修订且不吞 evaluation；broad HPO budget 5 initial+25 new。Agentic HPO family score 0.554，高于 Direct 0.519、GP-BO 0.432、TPE 0.344；但 Bayesmark tasks 含 `hidden_layer_sizes` 等结构字段，不能视为固定架构 HPO。论文的 token cost 只以图示官方 list price 呈现，缺 exact calls/tokens/wall-time/GPU/energy 总账本。

## 重点结论与下轮

- ASI-Arch 首次给出本轮较大规模 autonomous architecture research 的分阶段 GPU 账本，但其 37.4% legality 只来自 120-attempt matched slice；今后必须把 novelty reject、sanity reject、debug retry、trained、verified 和 promoted 分层记录。
- AgenticBBO-Bench 的“invalid 不吞 objective evaluation”与 best-so-far trajectory score 值得借鉴，但公平性必须再加 attempted trials、token、wall-time 和 tool compute，否则 evaluation-matched 仍不是 end-to-end matched budget。
- 两篇小模型传统方法说明“体积小”不等于成本闭合：一篇有 Pi latency/power、缺 memory/search energy；另一篇有 candidate/distinct/CPU-hours、缺真实硬件。当前 Conv1d baseline 应把这些字段合并进同一 manifest。
