## 本次补回解析（8 篇）

### LLM × NAS（2）

1. **Cognitive-YOLO**（`2512.12281v2`）：真实生成 Backbone/Neck/Head 拓扑，四个检测数据集上的合成模型约 1.9M–2.7M 参数；但候选、失败、LLM/GPU 预算和经典 NAS 对照未报告，属于架构合成证据而非严格搜索效率证据。
2. **LEMUR 2**（`2607.06839v1`）：14k+ 架构、750k+ training records，包含 LLM synthesis、NN-RAG、AST/GA/RL 生成以及 Android/Unity 部署元数据。它是 benchmark/data infrastructure，不是统一预算下的单一 NAS 算法比较。

### 固定架构 HPO（1）

3. **GenomeHarness**（`2608.21916v1`）：冻结 DNABERT2/NTv2-100M-Multi 结构，只搜索 learning rate、warmup、weight decay、layerwise decay、epochs 等 recipe；每 task 一小时 launch budget、4×L20、平均 36–57 completed trials、166–193 cumulative GPU-min，freeze 后三 seeds。缺少 random/TPE/CMA-ES/pure-LLM 同预算基线。

### Mixed search space / AutoML（4）

4. **NOVA**（`2606.27243v3`）：生产推荐模型中同时改变 topology、feature configuration、交互模块和部分训练字段；每 task 最多 10 轮、每轮 4 candidates、最多 1 次 offline evaluation。L2/L3 EPR 为 53.3%/51.7%，但 LLM 成本未在方法间匹配。
5. **Self-Evolving Recommendation System**（`2602.10226v3`，RecSys 2026）：Fast/Slow Loop 同时优化 optimizer、architecture、reward 与 recipe；报告生产 A/B 和六个月约 $20k LLM 成本。它是开放式 MLE 系统，不可转述为 fixed-recipe NAS 或 fixed-architecture HPO。
6. **Agentic Bayesian Optimization**（`2608.00316v2`）：Sara + lenz 让 Agent 控制 BO policy，保留显式 surrogate uncertainty。LCBench 的 7-D 空间包含 `max_units` 和 `num_layers`，因此按仓库规则为 mixed，不是严格 HPO；80 evaluations 后 Sara/LLAMBO/Ax 最终表现接近。
7. **LACE**（`2608.16416v1`）：搜索完整 scikit-learn pipeline programs。计划 102,000 candidates，实际 101,959；69.6% valid，70,998 valid 中 65,298 unique signatures。协议对 attempted/invalid/duplicate 记账很有价值，但对象不是神经架构。

### NAS evaluator / proxy discovery（1）

8. **Bi-EZP**（`2608.21927v1`）：LLM 演化 zero-cost proxy 聚合程序，CMA-ES 校准连续系数；`P=20`、`T=20`、每程序最多 1,500 CMA-ES evaluations。它不直接搜索架构，且表中 0.06/0.07 GPU-days 不含一次性 proxy discovery 成本。

## 重点结论

- **断档补救必须用覆盖水位线，而不是“最后一次尝试日期”。** 本次完整基线覆盖到 2026-09-21，后续只有在 ID 收集、分页、筛选和正文处置都完成时才推进 `coverage_end`；失败区间应保留并重扫。
- **更新时间和提交时间都要查。** 本轮 68 个候选属于旧提交、窗口内更新；只用 `submittedDate` 会漏掉 Cognitive-YOLO、NOVA 和 Self-Evolving Recommendation 等新版证据。
- **变量审计改变分类。** Agentic BO 自称 HPO，但 LCBench 同时搜索 depth/width；NOVA/Self-Evolving 同时改结构、feature/recipe/reward；只有 GenomeHarness 明确锁定 backbone。
- **失败与成本口径仍是核心缺口。** LACE 的 attempted/invalid/unique-signature 记账最完整；NOVA 有 per-stage tokens/cost；GenomeHarness 有 GPU minutes。没有一篇同时统一候选、训练、GPU、墙钟和 LLM 预算。
- **硬件感知证据仍不足。** LEMUR 2 有 Android/Unity 测量基础设施，Bi-EZP 把 device latency 留作未来工作；没有新论文同时把质量、真实 latency、peak memory、energy 和成本纳入 LLM Agent Pareto 闭环。
- **Conv1d Transformer 仍是空白。** 本次没有发现直接针对 4–10 层 Conv1d Transformer、block/cell/op typed space 的新工作。
- `quality_proxy` 与 `latency_proxy_ms` 继续仅作控制流占位符；本文所有数值均为论文作者结果，不是仓库实测。
