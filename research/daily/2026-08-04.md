## 本次新增解析（2 篇）

1. [GraphIR: Architecture-Level Search States for LLM-Guided Neural Architecture Evolution](https://arxiv.org/abs/2608.01633)（2026, arXiv）
   - 新建：[结构化解析](../papers/parsed/2026-arxiv-graphir.md)。
   - 用 computation skeleton、mutation surface 与 validity envelope 显式暴露 tensor flow、可变 components 与 interface/shape dependencies，源程序仍由 LLM 编辑。
   - OpenEvolve + Qwen3-Plus 的 MNIST1D representation 对照固定 100 evolution iterations；GraphIR 10 seeds，generic representation baselines 各 3 seeds，并报告 invalid、shape error 与 RTX 3090 端到端 GPU-hours。
   - 关键限制：无作者代码；CLRS aggregate 混合原论文数字与重跑，不是所有方法 matched budget；缺少 LLM calls/tokens/费用、duplicate/OOM 账和真实 latency/memory Pareto。

2. [Long-Horizon Autonomous Architecture Research with a Language-Model Agent: A Behavioural Case Study](https://arxiv.org/abs/2608.01995)（2026, arXiv）
   - 新建：[结构化解析](../papers/parsed/2026-arxiv-long-horizon-architecture-research.md)，按 `mixed-search-space` 归档。
   - 单个 CLI 型 frontier LLM 维护研究日志，逐轮提出一个假设、修改 code/config、训练、解释并 commit/revert；约 117 个列明 hypotheses、约 130 次实质训练、约 2,400 GPU-hours。
   - 它搜索真实 channel-attention Vision Transformer，但同时改变结构、配置、dataset、scale 与阶段协议，不能作为固定 recipe 纯 NAS 的效果证据。
   - 关键限制：单 Agent/单问题/单长轨迹、无 matched human/算法对照、具体模型与完整训练代码暂因双盲未公开、LLM token 只有数千万级估算。

## 已筛选、暂不入库

- [Convergence Theory for Iterative LLM-Based NAS](https://arxiv.org/abs/2605.30103) 建模 iterative LLM-NAS、delta validity 与 proxy reliability，但它与 Delta-NAS 共享 22-cycle/3-LLM/3,300-architecture 实验语境；继续等待定理假设、独立性与代码核验，不把摘要中的理论主张直接入库。

- OpenReview 的 CoLLM-NAS、few-shot LEMUR generation 与 SWNAS 是以前未覆盖的高相关候选；本轮发现页出现 browser challenge/429，未获得足够稳定正文证据，留待后续逐页核验后再决定入库。

## 重点结论与后续问题

- **架构状态是 raw code 与 typed action 之间的桥梁。** GraphIR 的 skeleton/surface/envelope 可转成 `block/cell/op/connectivity + shape/interface/dependency` 的窄结构接口，由本地 builder/validator 生成代码。
- **validity 必须细分而非只报成功率。** 至少分别记录 schema、shape、interface、duplicate、OOM、timeout 与 divergence，并以 attempted candidates 为主预算。
- **单冠军 greedy loop 会产生路径依赖。** 长时程案例提示增加 Pareto archive、显式 diversification 与 regime-aware revalidation；这些仍需多 workflow、多 model、多 seed 的受控实验。
- **NAS/HPO 继续分轨。** 长时程案例同时修改 code/config 和跨阶段 protocol，只能作为 mixed-search-space workflow 证据，不能把其 accuracy trajectory 转移到固定 recipe NAS。
- **成本账要比 GPU-hours 更完整。** GraphIR 缺 LLM calls/tokens/费用，长时程案例的 token 只有估算且 GPU 型号混合；本仓库需同步报告 attempted trials、training steps、GPU-hours、LLM calls/tokens/费用与 human interventions。
- **没有新的设备 Pareto 结论。** parameter count、FLOPs、search GPU-hours 和 invalid rate 都不是实测 latency、peak memory 或 energy；`quality_proxy` 与 `latency_proxy_ms` 继续只作为控制流占位符。
- **下一轮优先级。** 获取 GraphIR 代码/NAS-Dependency artifact；核验 OpenReview 的 CoLLM-NAS 与 few-shot LEMUR 全文；继续审查 `2605.30103` 的定理假设与 OrchNAS 的真实测量 protocol。
