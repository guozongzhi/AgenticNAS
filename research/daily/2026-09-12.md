## 本次新增解析（2 篇）

1. [LM-Searcher: Cross-domain Neural Architecture Search with LLMs via Unified Numerical Encoding](https://aclanthology.org/2025.emnlp-main.478/)（EMNLP 2025 Main，DOI `10.18653/v1/2025.emnlp-main.478`）
   - 新建：[结构化解析](../papers/parsed/2025-emnlp-lm-searcher.md)；[代码](https://github.com/Ashone3/LM-Searcher)、[模型](https://huggingface.co/Ashenone3/LM-Searcher)、[228K 轨迹数据](https://huggingface.co/datasets/Ashenone3/LM-Searcher-Trajectory-228K)均可访问。
   - 把离散结构变量编码为 `NCode`，以 history-performance 和 10-candidate pool 训练/调用 LLaMA-3.1-8B 作为 reranker；每轮只选一个候选做真实或代理评估并写回 history。
   - 搜索对象包含 NAS-Bench-201 cell/op、DARTS、32 个 SAM LoRA ranks、48 组 diffusion LoRA ranks、Transformer embedding/hidden/head/1–6 decoder layers 和 NAS-Bench-ASR DAG，是真实 neural/adaptor architecture search，不是 Agent workflow 搜索。
   - 预算不是统一口径：SFT 使用 228K trajectories、1 epoch、8×40GB；CIFAR-10 为 500 candidates × 10-epoch proxy、top 5 × 200 epochs，SAM 为 200 candidates × 1 epoch、top 1 × 30 epochs，translation 采评 3K sub-transformers。LLM tokens、SFT GPU-hours、搜索 wall-time和多数 OOD 完整预算未报告。
   - Table 2 的随机/进化/任务专用基线没有逐任务证明完全 matched-budget。NAS-Bench-201 报五 runs，但 segmentation 的五次结果是最终架构 training repeats，不是五个 search seeds。
   - 公共 GitHub 只有 10 个文件：`search.py` 的 reward 是随机占位，且第五轮后候选生成参数类型错误；缺 benchmark evaluators、trajectory builder、OOD scripts、seed manifests 和 logs，不能视为 paper-exact 复现。

2. [Closed-Loop LLM Discovery of Non-Standard Channel Priors in Vision Models](https://link.springer.com/chapter/10.1007/978-3-032-31920-3_42)（ICPR 2026，DOI `10.1007/978-3-032-31920-3_42`）
   - 新建：[结构化解析](../papers/parsed/2026-icpr-closed-loop-channel-priors.md)；[NN-GPT](https://github.com/ABrain-One/NN-GPT) 与 [NN-Dataset](https://github.com/ABrain-One/NN-Dataset) 可访问。
   - AST/TorchFX 先生成 shape-consistent AlexNet channel variants，OlympicCoder-7B 再以 CIFAR-100 单 epoch validation feedback 做 22 轮生成与 LoRA fine-tuning。
   - 220 次 proposal 只有 20 个 valid（9.09%）；best proxy 从 0.250 到 0.311，是 +6.1 points / +24.1% relative，不是完整训练或独立 test accuracy。
   - early/late valid means 为 0.226/0.273，作者报 t-test `p=0.0033` 和 permutation `p=0.0077`；但同一 adaptive trajectory 的候选并非 iid/exchangeable，且只有一个 search seed，不能把 p-value 当闭环因果优势。
   - 没有 matched-budget random/evolution/AST-only controller。Fig. 5 只在 20 个 valid 点上事后画 accuracy-parameter 前沿；search 未显式优化参数量，也没有 latency、energy、memory 或 HV，因此不是硬件 Pareto 证据。
   - 论文称 channel-only/标准训练，但公开 prompt 同时输出 `<hp>`、`<tr>`、`<nn>`并允许修改 batch、transform 和 supported hyperparameters；本索引保守归为 `mixed-search-space`，直到 paper manifest 证明非结构字段固定。
   - 论文称 1,129 个 AST variants，当前 NN-Dataset HEAD 只有 1,126 个对应 model files；当前 tune script context 8,192 也与论文 16,384 不同，且没有可映射 20 个 AirNet valid candidates 的冻结轨迹。

## 已筛选、暂不入库

- [CoRA-NAS](https://arxiv.org/abs/2609.11884) 是 2026-09-11 新公告的真实 NAS，但方法是 zero-cost proxy consensus + learning-curve residual/ExtraTrees，不含 LLM/Agent proposal loop；保留为 proxy-ranking 邻接基线，不纳入 LLM-NAS 主线。
- [R4Tun](https://arxiv.org/abs/2609.11360) 用 LLM 调整 SAM4Tun 点云分段管线参数，搜索对象是专家流程参数，不是真实神经网络结构；排除。
- [Generative Replay Mitigates Sample Starvation in Quantum Architecture Search](https://arxiv.org/abs/2609.11248) 搜索量子电路并使用 RL/generative replay，不是 classical neural architecture，也无 LLM proposal loop；排除。
- [Device-First Feedback](https://arxiv.org/abs/2608.00078) 仍是高优先级未覆盖论文：需补回此前并发阻塞时未发布的独立笔记，重点审计 test-feedback、SM-P613 latency、单 seed 和 scalar accuracy/latency ratio。
- [Similarity-Guided Curriculum Fine-Tuning of LLMs for Neural Architecture Synthesis](https://arxiv.org/abs/2607.11591) 与 [AgenticRS-EnsNAS](https://arxiv.org/abs/2603.20014) 是后续候选；前者需区分 synthesis dataset 与 search evidence，后者需确认真实结构变量和 ensemble/decomposition 边界。
- [Convergence Theory for Iterative LLM-Based Neural Architecture Search](https://arxiv.org/abs/2605.30103) 仍待核对 theorem assumptions、adaptive independence、3,300 candidates 账目和 paper-exact code。
- 本轮仍未发现直接针对 4–10 层 Conv1d Transformer 的新 LLM/Agent NAS 或固定架构 LLM-guided HPO 论文。

## 重点结论与后续问题

- **ranking 是比自由 code generation 更可控的 proposal interface。** LM-Searcher 每轮在固定候选池选一个，天然保证 typed action validity；Channel Priors 的开放 code输出则损失 90.91% proposal budget。
- **统一 encoding 不等于统一成本。** `NCode` 可跨 cell、LoRA 和 Transformer，但 evaluator/supernet/full training 成本完全不同；报告必须拆分 amortized SFT 与 per-search marginal cost。
- **channel-only 要由执行层锁死。** prompt 文案不足以保证 scope；应由 schema/evaluator拒绝 optimizer、lr、batch、augmentation 和 topology 变化。
- **统计不能忽略 adaptive dependence。** closed-loop early/late 候选来自不同模型与 history，普通 t/permutation p-value不自动具有 iid 因果解释。
- **Pareto 必须是明确目标和测量。** 20 个点的事后 accuracy-parameter scatter 不能替代 matched-budget 多目标 NAS；真实硬件需报告 latency/energy/peak memory、设备、batch、warmup和重复次数。
- **公开 artifact 要冻结并可重建 headline。** LM-Searcher 缺完整 evaluator；Channel Priors 的 current repo 数量、context 与论文漂移。下一步需要 paper commits、manifests、seeds和 stage-wise failure/cost账。
- **与当前空间的直接映射。** 把 LM-Searcher 的 `NCode` 升级为有版本的 typed schema，并把 AST/TorchFX dependency grouping用于 Conv1d/head/residual validity；固定 10-candidate pools，可公平比较 LLM reranker、random、evolution和 surrogate。
- `quality_proxy` 与 `latency_proxy_ms` 继续只能作流程占位符；本轮没有证据允许把它们写成研究结果。
- **下一轮优先级。** 先补回 Device-First Feedback，再解析 Similarity-Guided Curriculum 或 AgenticRS-EnsNAS；同时继续追踪 LM-Searcher 完整 scripts 和 Channel Priors paper snapshot。
