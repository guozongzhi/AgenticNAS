3. **BeFit**（`2611.23520v1`）—传统 `mixed-search-space / hardware-aware NAS`：同时搜索结构、Bernstein degree 与 learning rate；有 Cortex-M4 真机 latency/RAM/flash，trial 初筛和 3-seed front，但 Bernstein/ReLU attempted trials 为 500/300 或 200/150，不等预算，energy 未测。
4. **ICICLE**（`2611.24469v1`，NeurIPS AXIOM Workshop）—传统 multi-fidelity HPO surrogate：PD1/TaskSet 可作 fixed-HPO，LCBench/Meta-Album 为 mixed。1,000-iteration/20-seed 与 1/4/16h 协议清楚，surrogate 预训练 GPU-hours 与失败账本缺失。
5. **HapBO**（`2611.25100v1`）—`Agentic BO / mixed-HPO 邻接`：搜索前一次性把语言先验编译为 acquisition multiplier，在线无 LLM feedback。HPOBench 16 queries×10 seeds；setup 约 15,001 tokens、在线 0 token/query，HapBO pooled fail%=0，但 serving GPU/energy 未报告。
