## 本次新增解析（2 篇）

1. [AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search](https://arxiv.org/abs/2603.20014)（arXiv v1，DOI `10.48550/arXiv.2603.20014`）
   - 新建：[结构化解析](../papers/parsed/2026-arxiv-agenticrs-ensnas.md)。论文给出面向离散 topology/block choice 的 LLM proposal + 双 proxy learner + 单调接受算法，但 NAS-Bench-201、Criteo/Avazu 和 production A/B 均仍是计划；公开 source 只有 TeX，没有代码、表格数据或可核验 benchmark artifact。
   - 精确的 ensemble-error 比较式保留新旧架构各自的 variance；摘要/headline 阈值进一步假设 `sigma^2(pi) ~= sigma^2(pi_old)`。正文称该假设由 Section 6 验证，但 Section 6 只有未来计划和不可核验内部 pilot，因此不能把阈值当作已验证的通用保证。
   - Algorithm 1 第 8 行把 `Delta E_i` 写为 `E_best - E(pi_i)`，与全文定义 `E(pi_i) - E_best` 相反；第 9 行直接代入同一阈值，导致伪代码的接受方向与定理定义不一致。`90x/100x` 也是设定 `M/N/C` 后的成本算例，不是实测加速。
   - 该稿搜索对象概念上是真实架构，但目前没有公开执行一次离散 LLM-NAS；feature-retention 闭式案例更接近数据/ensemble diversity control。故索引为理论型 `llm-nas`，不把内部 pilot 或未来路线图写成实证结果。

2. [Convergence Theory for Iterative LLM-Based Neural Architecture Search: A Parametric Cross-Entropy Framework with Closed-Form Proxy Reliability](https://arxiv.org/abs/2605.30103)（arXiv v1，DOI `10.48550/arXiv.2605.30103`）
   - 新建：[结构化解析](../papers/parsed/2026-arxiv-convergence-theory-llm-nas.md)。论文把 iterative LoRA + elite corpus 写成 parametric cross-entropy projection，并新增 43 个 proxy/full-training pairs；3,300 architectures、22 cycles 和三种 7B LLM 的主要跨周期数据来自已解析的 Delta-Based NAS，不是新的独立搜索。
   - 随文 `cycle_data.csv` 恰有 `66 = 3 x 22` 行，按每行 50 proposals 对应 3,300；delta apply rate 均值 0.7133。新实验在单张 RTX 4090 上把每种 LLM 的 top-20 尝试训练 50 epochs，最终有效 N 为 16/15/12，共 43，约 4 GPU-hours。
   - 公开 CSV 不支持“质量单调上升”的强读法：逐 cycle `mean_acc` 下降次数为 DeepSeek 9、Mistral 12、Qwen 12；普通 trailing 3-cycle mean 仍分别下降 10、10、13 次，且 Mistral/Qwen 最后一轮低于第 0 轮。正文理论又依赖未验证的 `quality-monotone projection`，有限样本只给 `-epsilon_t` slack，不能直接使用单调收敛定理。
   - proxy 相关性的 Mistral 样本混合 MNIST/CelebA/SVHN，而 Qwen/DeepSeek 只含 MNIST；跨任务 accuracy variance 会混入 `sigma_arch`。这可以支持“先测 proxy SNR”的诊断，但不能证明跨架构、跨任务的一 epoch排序一般可靠。

## 已筛选、暂不入库

- [SAGE-Loop](https://arxiv.org/abs/2609.12455)（`2609.12455`）是 2026-09-14 新公告中的 LLM-driven AutoML：它按轮生成 tabular feature、任意 classifier/regressor/clusterer code，并在最多 10 个候选、每候选最多 10 次 HPO 后选 ensemble。目标不是稳定定义的神经网络架构，且 feature/HPO/algorithm family/ensemble 同时变化；代码也只承诺“发表后发布”，因此不作为真实 LLM-NAS 或固定架构 LLM-HPO 条目。
- [Autonomous Research for Open-Ended Problems](https://arxiv.org/abs/2609.13073)（`2609.13073`）搜索 telecom retrieval 的表示、采样、数据、训练和架构；但最佳结果仍是固定 `all-mpnet-base-v2` bi-encoder 的数据/长度/epoch/lr 调整，论文明确说 agents 很少改变 encoder，也未尝试 reranking/augmentation/ensemble。它属于广义 MLE agent case study，不提供可分离的真实架构搜索证据。
- [RiPPLE](https://arxiv.org/abs/2609.12418)（`2609.12418`）是 anchor early-training + label propagation 的传统 NAS 排名器，没有 LLM/Agent proposal loop；保留为低保真评估邻接基线，不建 LLM-NAS 笔记。
- `T-GADE`（`2609.12286`）演化 bin-packing heuristic artifacts，`PACEvolve`（`2601.10657` replacement）优化通用 self-evolving agent memory；搜索对象都不是神经网络架构。
- 本轮仍未发现直接针对 4-10 层 Conv1d Transformer 的新增 LLM/Agent NAS、固定架构 LLM-guided HPO，或同时报告真实 latency/peak memory/energy 的新 Pareto 工作。

## 重点结论与后续问题

- **理论条件要落到可执行 contract。** AgenticRS 的可复用思想是以 accuracy 与 ensemble prediction correlation 联合 gate 候选；但实现前必须修正 `Delta E` 符号、保留 variance-change 项，并用公开数据做 matched-budget calibration。
- **渐近 CE 叙述不能替代有限预算证据。** 累积 corpus、静态 prior、novelty filter、LoRA projection 和 adaptive samples 都改变了标准 CE 条件；每一步都应单列可检验假设，而不是从 smoothed curve 反推收敛。
- **proxy fidelity 必须 task-conditional。** 跨数据集 accuracy variance 会人为抬高相关性；应在相同数据集/训练协议内估计 SNR，再用 nested bootstrap 或多 search seeds 给出不确定性。
- **新稿进一步强调边界。** SAGE-Loop 的 repair/validation-only feedback 可作为工程参考，但通用 classifier code 与 ensemble 选择不能冒充 neural architecture search。
- `quality_proxy` 与 `latency_proxy_ms` 继续只能作流程占位符；本轮没有证据允许把它们写成研究结果。
- **下一轮优先级。** 检查 2026-09-15 新公告；追踪 AgenticRS 是否发布 journal validation/code，复核 convergence theory 的勘误或新版本，并继续寻找 4-10 层 Conv1d Transformer 与真实设备 Pareto 工作。
