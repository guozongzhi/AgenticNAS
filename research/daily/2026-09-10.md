## 本次新增解析（2 篇）

1. [CoLLM-NAS: Collaborative Large Language Models for Efficient Knowledge-Guided Neural Architecture Search](https://arxiv.org/abs/2509.26037)（CVPR 2026 Workshops / CVPR-NAS Oral）
   - 新建：[结构化解析](../papers/parsed/2026-cvprw-collm-nas.md)；[CVF 终版](https://openaccess.thecvf.com/content/CVPR2026W/CVPR-NAS26/html/Li_CoLLM-NAS_Collaborative_Large_Language_Models_for_Efficient_Knowledge-Guided_Neural_Architecture_CVPRW_2026_paper.html)。未发现可确认的作者代码仓库。
   - 有状态 Navigator 从历史验证反馈形成策略，无状态 Generator 每轮生成 10–20 个结构化架构，Coordinator 完成合法性、资源约束、去重与共享超网评估。
   - 空间覆盖 MobileNet block 参数、ShuffleNet op、NAS-Bench-201 cell，以及 AutoFormer depth/width/heads/MLP；AutoFormer 深度为 12–16，不在当前 4–10 层重点区间，也没有 Conv1d。
   - 宏观空间以 250 个候选对比 EA 的 1,000 个候选，作者报告 4.6–10× search-phase GPU-day 降低和最高 0.7 point Top-1 提升；成本明确排除超网训练，且没有 tokens、独立 LLM GPU-hours、同 250-candidate EA 或完整 traces。

2. [AutoMCU: Feasibility-First MCU Neural Network Customization via LLM-based Multi-Agent Systems](https://arxiv.org/abs/2605.21560)（2026, arXiv v1）
   - 新建：[结构化解析](../papers/parsed/2026-arxiv-automcu.md)；论文未给作者代码链接。
   - Proposal Agent 输出可构造的 CNN JSON，先经 schema/shape 与 STM32Cube.AI 的 SRAM/Flash/operator gate，只有可行候选才训练；Supervisor、Training、Evaluation/Conversion 模块用状态隔离摘要交换结果。
   - 论文报告十次重复、GPU-hours、tokens/API 费用，并在 STM32F407VET6 与 STM32H723ZGT6 上人工完成 firmware 集成、flash 和执行验证。
   - 关键限制：主表未给最大候选数和完整训练 recipe；与 μNAS/ColabNAS 不同搜索空间与预算；HAG 消融同时移除了 LLM proposal；失败 run 被排除出 accuracy/resource 均值；实机没有 latency/energy。

## 重点结论与后续问题

- **候选效率与端到端成本要分层。** CoLLM-NAS 的 4–10× 只比较排除超网训练的搜索阶段，且改变 1,000→250 候选预算；必须另报超网、LLM serving、候选 validation 与摊销次数。
- **部署 gate 比参数代理更接近真实约束，但仍不是完整设备 Pareto。** AutoMCU 验证了 operator/RAM/Flash/compile/execute，可它没有 latency、peak runtime memory 或 energy；下一步必须板载测量。
- **多 Agent 结论需要正交消融。** CoLLM-NAS 应在相同 calls/tokens 下比较单 LLM 与双角色；AutoMCU 的 HAG 消融同时改 proposal 和 gate，不能把全部提升归因于 hardware-in-the-loop。
- **预算与失败口径必须统一。** 同时记录 attempted、schema-valid、backend-feasible、trained、deployed 候选；失败 run 既要计入 success rate，也要以 intention-to-run 口径报告成本/质量。
- **与当前空间的直接映射。** CoLLM-NAS 的 block/cell/op typed generation 和 AutoMCU 的 backend gate 可迁移；两篇都未直接验证 4–10 层 Conv1d Transformer，不能搬运视觉准确率结论。
- **下一轮优先级。** 解析 OCR AutoML 与 few-shot/LEMUR；补查 LM-Searcher 终版/代码；若能取得 CoLLM-NAS/AutoMCU 作者实现，冻结 commit 后审计完整 calls/tokens、训练 recipe 和失败 traces。
- `quality_proxy` 与 `latency_proxy_ms` 继续只能作控制流占位符；本轮没有任何证据允许把它们写成研究结果。
