## 本次新增解析

1. [SEKI: Self-Evolution and Knowledge Inspiration based Neural Architecture Search via Large Language Models](https://arxiv.org/abs/2502.20422)（2025, arXiv）
   - 新建：[结构化解析](../papers/parsed/2025-arxiv-seki.md)。
   - 最直接的可复用点是：把已评估的高质量候选存为有界 memory，并从 top-k 随机抽样一部分作为后续 proposal 的上下文，显式对抗重复和局部最优。
   - 不能直接照搬 LLM 输出架构的做法；本项目应继续以受 schema 约束的 declarative mutation 为唯一 Agent 动作。

## 研究判断与下一步

- 下一次应优先寻找带有公开代码、统一候选/训练/硬件/LLM 预算和多 seed 方差的 LLM-guided NAS 工作。
- 在本项目中，可将 SEKI 的随机 memory sampling 作为可控变量；实验报告必须并列 action validity、duplicate rate、hypervolume 和 seed variance。
- 任何 latency/quality proxy 只能作为控制流占位符。硬件/端到端性能结论需来自真实测量，并与 LLM 费用和延迟分开记账。
