# AutoResearcher 工作台 Demo

从本目录启动 Python 静态服务：

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 [本地工作台](http://127.0.0.1:8766/)。无需构建、账号或 API 密钥。

## 演示路径

1. 打开预置经验 `KB-001 · v1`，查看适用条件、判断依据和验收标准。
2. 提交仿真，在实验任务页观察状态、停止或下载日志。停止后可回到经验库重试。
3. 等待任务完成后回到同一条经验，再提交训练和回归评测。
4. 打开模型评测查看预设的基线与候选结果。仅内置首个条目的初始版本带有预设分数。
5. 新建或编辑经验、填写可选 Wiki 来源链接并确认草稿。编辑会生成新版本，原实验仍绑定原版本。

首次使用已确认、尚无任务的版本时，也可点「运行完整流程」自动串联仿真、训练和评测。打开工作台时会推进流程，关闭后暂停提交后续阶段。停止当前任务或编辑出新版本后，原自动流程不会再提交下一阶段。

演示数据存放在当前浏览器站点的 localStorage。任务按本地时间推进，日志和评测分数是演示数据。没有连接真实 Wiki、MCP 服务或模型训练平台，也没有运行实际仿真。

## 接口边界

`model.js` 包含演示任务的提交、状态和日志行为。接入真实平台时，在服务端映射 MCP 的仿真提交、训练提交、取消、状态查询与日志下载，并保留外部任务 ID、经验版本、输入配置和产物标识。前端只调用该服务端接口。Wiki 同步和独立评测可分别接入，分别保留 Wiki 修订标识及评测集版本。
